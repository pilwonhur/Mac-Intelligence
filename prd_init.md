

What following is the list of what I want for this project
- On Macbook
- When there are some texts that I want to ask to AI while reading web pages or documents, I want to select the texts, and then I want to ask to AI to answer the texts.
- Right-click on the selected texts, and then I want to see the AI answer.
- Quick actions or services or keyboard shortcuts can be used to ask to AI to answer the texts.
- When I click the menu, it will open the pop-up window.
- Then, I can type detailed question about the selected texts to AI, and then I want to see the AI answer.
- I wonder if it is also possible for the AI to understand the context of the selected texts, meaning if the AI has access to the full web page or document containing the selected texts.
- In addition to the selected texts, I can also type some other unrelated questions to AI.
- The popup window will be closed when I click the close button.
- I can select AI models from the pop-up window.
- I can select languages from the pop-up window.
- The pop-up window should not interfere with the user's work.
